# Support

## Where to ask

- **Usage questions, configuration help, "how do I…":** open a [Q&A discussion](https://github.com/termyte-labs/termyte/discussions/categories/q-a) or a [question issue](https://github.com/termyte-labs/termyte/issues/new?template=question.md).
- **Bug reports:** use the [bug report issue template](https://github.com/termyte-labs/termyte/issues/new?template=bug_report.md).
- **Feature ideas:** use the [feature request template](https://github.com/termyte-labs/termyte/issues/new?template=feature_request.md) or start a discussion first.
- **Security issues:** follow [`SECURITY.md`](./SECURITY.md) — do not file a public issue.

## Before opening an issue

1. Run `termyte stats` and check that the DB path and counts look right.
2. Confirm the failing agent is on the [supported-agents list in the README](https://github.com/termyte-labs/termyte#supported-agents).
3. Search [existing issues](https://github.com/termyte-labs/termyte/issues) and [discussions](https://github.com/termyte-labs/termyte/discussions) for your problem.
4. If you have a minimal reproduction, include it. Hook payload examples live in `test/`.

## Response targets

The project is best-effort maintained. There is no guaranteed SLA, but:

- Bug reports: maintainer acknowledgment within ~7 days.
- Security disclosures: see `SECURITY.md` (3 business days).
- Pull requests: review within ~7 days for straightforward changes.
